# Insulin Resistance iOS Prototype

This is a SwiftUI static prototype with local mock data. Open `Package.swift` in Xcode and run the `InsulinResistanceApp` target on an iPhone simulator.

Implemented flows:

- Welcome
- Create profile
- Home
- Check-in method selection
- Manual daily check-in
- AI-style Cloudy check-in
- Completion
- Daily insights
- Weekly risk and trends
